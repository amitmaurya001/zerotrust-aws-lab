Architecture
NIST SP 800-207 coverage

Every pillar has a concrete, demoable control.

01 /
Identity
Okta OIDC + group-based access. JIT ephemeral users auto-provisioned and auto-revoked. Cognito external identity layer.
02 /
Device
Cloudflare WARP + OS version posture check. Admin page blocked on any unregistered device.
03 /
Network
Dedicated private subnet per team. Zero inbound security group rules. Cloudflare Tunnel — outbound only.
04 /
Application
Cloudflare Access per-app policies. mTLS on monitoring service. HMAC-SHA256 + nonce on service-to-service calls.
05 /
Data
RDS SSL enforced. All secrets in SSM SecureString. AWS Config continuous compliance — 4 rules always running.
06 /
Audit
CloudTrail immutable audit log. CloudWatch alarms. Per-session JIT audit trail with real Cognito identity.
